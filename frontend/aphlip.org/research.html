01 / RESEARCH QUESTION

What can galaxy structure tell us about evolution?

Post-starburst, or E+A, galaxies are of interest because their recent star-formation histories and present-day structure can offer clues about how galaxies change. Disturbed morphology may be consistent with mergers or interactions, but morphology alone does not confirm an E+A classification.

This project explores whether multi-band CAS measurements can provide a useful structural view of candidate galaxies. It is an early, catalog-level prototype intended to guide further validation.

02 / DATA & CANDIDATES

From a survey catalog to a working sample.

The query workflow uses the Rubin Science Platform Table Access Protocol (TAP) and the DP0.2 object catalog. The project README describes an initial catalog query followed by Green Valley color and magnitude cuts.

SelectionRange
u-band magnitude15.0 ≤ u ≤ 21.0
u − g color1.0 ≤ u − g ≤ 1.8
g − r color0.3 ≤ g − r ≤ 0.85

The README reports 103 candidates after applying these cuts. They are Green Valley candidates, not a spectroscopically confirmed E+A sample.

03 / MEASUREMENT FRAMEWORK

Three measures, across six bands.

The workflow aims to calculate Concentration, Asymmetry, and Smoothness separately for each candidate in the u, g, r, i, z, and y bands.

C

Concentration

Compares the radii containing 80% and 20% of the light.

C = 5 log10(r80 / r20)
A

Asymmetry

Compares a light distribution with its 180°-rotated counterpart.

A ≈ Σ|I − I180| / Σ|I|
S

Smoothness

Compares the flux with a smoothed version to capture small-scale structure.

S ≈ Σ|I − IS| / Σ|I|

04 / SCOPE & LIMITATIONS

A prototype with clear next steps.

The project README identifies several areas that require further development before interpreting measurements as physical morphology results:

  • The current calculations use catalog-level flux values, not full two-dimensional galaxy images.
  • Radii are approximated from shape moments and need validation against direct measurements.
  • Asymmetry uses a one-dimensional reversed flux array rather than rotating an image about a galaxy center.
  • Smoothness is calculated from a one-dimensional array, and background terms are not explicitly subtracted.
  • The photometric color cuts identify candidates; they do not establish a spectroscopic E+A classification.
i

These measurements are best understood as preliminary workflow outputs. Image-based implementation and validation are needed before drawing morphological conclusions.
