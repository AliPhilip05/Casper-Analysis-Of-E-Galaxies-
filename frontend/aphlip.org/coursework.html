CSC 326 · GROUP ASSIGNMENT · C++

Patient flow manager.

The assignment asks for an interactive program to manage hospital check-in and check-out, with patient records located by name through a hash table. A separate priority scheduler handles requests for three operating rooms.

DATA STRUCTURES

Hash table for patient records; priority queue for operating-room scheduling.

SCHEDULING RULE

Priority from 1 to 10, with first-come, first-served ordering among equal priorities.
